## About

I teach people to build software, and I build it myself.

For more than five years I have trained college students and corporate teams in Java, full stack development, data structures and algorithms, Python and AI/ML. My sessions are hands-on: less slideware, more code, labs and projects that look like real work.

I run [Xcode Academy](https://xcodeacademy.com), which delivers practical technology training to colleges, universities and corporate L&D teams.
